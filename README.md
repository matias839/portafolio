# Portafolio Personal - Matías Ignacio Sandoval

Este repositorio contiene el código fuente de mi página web de **portafolio personal**, desarrollada para presentar mi perfil como estudiante de Informática, mi formación académica, mis proyectos y mis habilidades en el área del desarrollo de software.

## 📄 ¿De qué trata la página?

La página es un sitio web estático de una sola página (*single-page*) con navegación fluida que reúne toda mi información relevante organizada en distintas secciones:

1. **Sobre mí**: Una presentación personal donde cuento quién soy, mi interés por la programación y la exploración de distintos lenguajes, mis pasatiempos y datos adicionales (ubicación e idiomas).
2. **Estudios**: Detalle de mi formación académica:
   - **Título Secundario con especialización en Informática** en el *Centro Educativo Arquidiocesano Espíritu Santo* y las materias principales de la orientación.
   - **Ingeniería en Sistemas de Información** en la *Universidad Tecnológica Nacional (UTN)* (2028 - 2033), abarcando materias como Sistemas de Información, Sistemas Operativos, Lenguajes de Programación, Matemática, Física, Química y Economía.
3. **Experiencia**: Muestra de los proyectos en los que trabajo, destacando el desarrollo y mantenimiento de un **Gestor de tareas en lenguaje C** con arquitectura eficiente y gestión manual de memoria mediante punteros.
4. **Habilidades**:
   - **Técnicas**: Desarrollo Fullstack (`HTML`, `CSS`, `JavaScript`), `C/C++`, `PHP`, y manejo de herramientas como `Git`, `GitHub`, `Antigravity IDE` y `Gemini AI`.
   - **Blandas**: Trabajo en equipo, aprendizaje autodidacta, rápida adaptación a nuevas herramientas y orquestación de agentes de IA.
5. **Contactos**: Enlaces y datos directos para comunicarse conmigo por correo electrónico, WhatsApp/teléfono, LinkedIn y mi perfil de [GitHub](https://github.com/matias839).

## 🛠️ Tecnologías utilizadas

- **HTML5**: Estructura semántica del contenido (`header`, `nav`, `main`, `section`, `article`, `footer`).
- **CSS3**: Estilos personalizados, barra de navegación superior fija (*sticky*), desplazamiento suave (*smooth scroll*), diseño de tarjetas con `Flexbox` y `CSS Grid`, y adaptabilidad para dispositivos móviles (*responsive design*).

## 📁 Estructura del proyecto

```text
portafolio/
├── index.html          # Estructura principal y contenido del portafolio
├── css/
│   └── style.css       # Estilos visuales y diseño responsivo
├── 28-300x240.webp     # Imagen de perfil
└── README.md           # Documentación del proyecto
```

## 🚀 Cómo visualizar la página

1. Cloná o descargá este repositorio.
2. Abrí el archivo `index.html` directamente en cualquier navegador web moderno.
